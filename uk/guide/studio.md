Application Studio (`appstudio`, у лаунчері — **Studio (GUI)**) — місце, де створюють застосунок: його метадані,
форми, модулі, ролі та звіти. Вона також записує застосунок у базу даних, запускає його під
налагоджувачем і дає ШІ-асистенту працювати поруч із вами.

## Вікно

| Частина | Що показує |
|---|---|
| **Дерево метаданих** (ліворуч) | Застосунок: кожен об'єкт, який він оголошує, згрупований за видом. Див. [Дерево метаданих](../metadata-tree/) |
| **Властивості** | Те, що виділено: у дереві, на формі, у таблиці. Кожна властивість має власну довідку |
| **Редактори** (у центрі, вкладками) | Об'єкт, форма, модуль, шаблон: усе, що відкрито з дерева |
| **Повідомлення, Стек викликів, Спостереження** (унизу) | Повідомлення компілятора та панелі налагоджувача, поки він приєднаний |

## Робота в дереві

Щоб додати об'єкт, клацніть правою кнопкою групу (**Довідники**, **Документи**…) → **Новий**. Права кнопка
на об'єкті дає **Редагувати**, **Видалити**, **Властивості** і відкриття його модулів. Подвійне клацання відкриває
власний редактор об'єкта: ім'я, синонім (заголовок, який бачать користувачі), коментар, форми за замовчуванням,
а також його реквізити, таблиці, форми, шаблони й модулі.

## Збереження та оновлення бази даних

| Дія | Що робить |
|---|---|
| **Зберегти** (панель інструментів) | Зберігає зміни відкритого редактора в застосунок, що редагується |
| **Оновити базу даних** (панель інструментів або **Застосунок → Оновити базу даних**) | Записує відредагований застосунок у базу і перебудовує її таблиці. До того Application Workspace виконує попередній |
| **Застосунок → Повернути застосунок бази даних** | Відкидає зміни й повертається до того, що зберігає база |
| **Застосунок → Зберегти застосунок / Завантажити застосунок** | Записує застосунок у файл або зчитує його з файлу |
| **Застосунок → Зберегти застосунок у файли… / Завантажити застосунок з файлів…** | Застосунок як папка текстових файлів, для системи контролю версій ([структура](https://github.com/open-enterprise-solutions/enterprise/blob/develop/docs/public/application-files.md)) |
| **Застосунок → Порівняти застосунки** | З файлом, із застосунком бази даних або два файли між собою |

Оновлення, що перебудовує збережені дані, потребує монопольного доступу до бази: спершу закрийте Application Workspace.

## Запуск і налагодження

| Меню «Налагодження» | Що робить |
|---|---|
| **Почати налагодження → Workspace (GUI) / Workspace (веб)** | Запускає Application Workspace на цій базі, на робочому столі або в браузері, з приєднаним налагоджувачем |
| **Запустити без налагодження** | Те саме, без приєднання |
| **Приєднати для налагодження…** | Приєднується до вже запущеного Application Workspace |
| **Продовжити, Крок із заходом, Крок з обходом, Зупинити налагодження** | Як зазвичай |
| **Замір продуктивності** | Вимірює час кожного клієнтського виклику та кожного рядка скрипту, поки працює Application Workspace |

Щоб поставити точку зупинки, клацніть на полі модуля. Точка зупинки може мати умову (права кнопка
→ **Умова точки зупинки…**), тож вона спрацьовує лише тоді, коли, скажімо, `i > 500`. Під час зупинки наведіть
вказівник на ім'я, щоб побачити його значення, або додайте його до **Спостереження**.

Налагоджувач працює через TCP, тому може приєднатися й до веб-сервера.

## Адміністрування

| Меню «Адміністрування» | Що робить |
|---|---|
| **Користувачі** | Користувачі бази та їхні ролі |
| **Активні користувачі** | Хто підключений зараз |
| **Журнал реєстрації** | Що зафіксувала база: входи, записи, проведення |
| **Веб-адреси** | На що база відповідає на веб-сервері, окрім своїх клієнтів |
| **Вивантажити базу даних / Відновити базу даних / Очистити базу даних** | База у файл і назад або очищення бази |
| **Вікно асистента** | Розмова з асистентом, що працює в цій базі |

**Інструменти → Тема…** вибирає світлий або темний вигляд.

## Доступ асистента (MCP)

**Інструменти → Параметри… → Доступ асистента (MCP)** відкриває порт асистента на вашому комп'ютері, тож
асистент, наприклад Claude Code, може читати й редагувати застосунок, оновлювати базу даних, виконувати код і
формувати звіти. Налаштування і перший запит:
[Створення застосунку з асистентом](https://github.com/open-enterprise-solutions/enterprise/blob/develop/docs/public/ai-quickstart.md).
