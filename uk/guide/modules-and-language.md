## Де живе код

| Модуль | Належить | Виконується |
|---|---|---|
| **Модуль об'єкта** | Довіднику, документу, регістру… | На подіях цього об'єкта: `BeforeWrite`, `OnWrite`, `BeforeDelete`, `OnDelete`, а для документа — `Posting` і `UndoPosting` |
| **Модуль менеджера** | Виду загалом | Код про всі товари, а не про один: пошук, вибір форми (`FormGetProcessing`), дані вибору |
| **Модуль форми** | Формі | Події форми та її команди |
| **Загальний модуль** | Застосунку | Загальні процедури, що викликаються звідусіль |

Обробник події — це процедура з ім'ям події. Ім'я фіксоване: процедура з іншим ім'ям
не викликається ніколи. Редактор показує перелік обробників, які пропонує об'єкт.

Код виконується там, де використовується об'єкт: у формі, іншому модулі, фоновому завданні, на
сервері застосунків. Модуль об'єкта ніколи не розраховує на вікно.

## Два діалекти, один компілятор

| | CES (у стилі C, за замовчуванням) | VES (у стилі ключових слів) |
|---|---|---|
| Функція | `function Compute(x) { return x * 2; }` | `Function Compute(x) Return x * 2 EndFunction` |
| Цикл | `foreach (item in items) { Message(item.Name); }` | `Foreach item In items Do Message(item.Name) EndDo` |

Обидва компілюються в той самий байткод. Нові застосунки використовують CES. Не змішуйте їх в одному
модулі: кожен порівнює та поєднує умови по-своєму — CES `==`, `!=`, `&&`, `||`, `!`;
VES `=`, `<>`, `And`, `Or`, `Not`. Ключові слова нечутливі до регістру, але кожне має рівно одне написання.

## Що є в мові

- Процедури й функції, `var`, `if`, `while`, `foreach`, `try … except`
- Лямбди із захопленням змінних у замикання
- Багаторядкові рядки, зручні для текстів запитів
- **LINQ**, скомпільований у байткод:
  ```c
  var q = from o in Orders
          where o.Total > Threshold
          orderby o.Date descending
          select { N = o.Number, V = o.Total };
  ```
- Вбудовані значення: таблиці й дерева значень, структури, відповідності, масиви, табличні документи,
  JSON і XML, клієнти HTTP і HTTPS, файли
- Байткод кешується для кожної версії застосунку, тож модуль компілюється один раз

## Доступ до даних

| Напишіть | Щоб отримати |
|---|---|
| `Catalogs.Products` | Менеджер товарів: створення, пошук, вибірка |
| `Documents.Receipt` | Менеджер надходжень |
| `InformationRegisters.Prices`, `AccumulationRegisters.Stock`… | Регістр |
| `Constants.CompanyName` | Константу |
| `Data.Catalogs.Products` | Той самий довідник як джерело LINQ |
| `new Query("SELECT …")` | Запит; див. [Запити і звіти](../queries-and-reports/) |

У модулі об'єкта документа `RegisterRecords.Stock` — це набір записів, які документ
запише в регістр `Stock` під час проведення.

## Спробувати код без бази

`coderunner` — чернеткове вікно: напишіть скрипт, перевірте його синтаксис, виконайте. Йому не потрібні ні база,
ні застосунок.

## Заголовки кількома мовами

Заголовок пишуть кожною мовою, яку оголошує застосунок, одним рядком:
`en = 'Employee'; ru = 'Сотрудник'; uk = 'Працівник';`. `Tstr(text)` вибирає в коді мову
користувача.
