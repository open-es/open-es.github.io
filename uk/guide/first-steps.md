На цій сторінці будується невеликий складський застосунок: товари, документ надходження, що оприбутковує
товари, регістр, що зберігає залишок, і звіт, що його читає. Це займає близько п'ятнадцяти
хвилин і по разу торкається кожної частини Application Studio.

## 1. Створіть базу

1. Запустіть `launcher` і натисніть **Додати**.
2. Назвіть базу `Stock`, виберіть **Файл (локальна база даних)** і вкажіть порожню папку.
3. Натисніть **Зберегти з'єднання**, виділіть базу й натисніть **Studio (GUI)**.

Application Studio відкривається з порожнім застосунком. Ліворуч —
[дерево метаданих](../metadata-tree/); якщо виділити в ньому будь-що, відобразяться його властивості.

## 2. Довідник товарів

1. У дереві клацніть правою кнопкою **Довідники** → **Новий**. Назвіть його `Products`.
2. Довідник уже має код і найменування. Додайте ще один реквізит: відкрийте довідник,
   у розділі **Реквізити** додайте `Unit` типу *Рядок*.

## 3. Регістр, що зберігає залишок

1. Клацніть правою кнопкою **Регістри накопичення** → **Новий**. Назвіть його `Stock`.
2. У розділі **Виміри** додайте `Product` типу *Посилання на довідник: Products*.
3. У розділі **Ресурси** додайте `Quantity` типу *Число*.

*Вимір* — те, у розрізі чого ведеться залишок. *Ресурс* — те, що підсумовується.

## 4. Документ надходження

1. Клацніть правою кнопкою **Документи** → **Новий**. Назвіть його `Receipt`.
2. У розділі **Таблиці** додайте таблицю `Goods` з колонками `Product` (*Посилання на довідник:
   Products*) і `Quantity` (*Число*).
3. У властивостях документа, у **Список записів регістру**, позначте `Stock`. Це
   регістри, у які документ може записувати.
4. Відкрийте його **модуль об'єкта** (права кнопка на документі → **Відкрити модуль об'єкта**) і напишіть,
   що робить проведення:

```c
procedure Posting(Cancel, PostingMode) {
    foreach (row in Goods) {
        var rec = RegisterRecords.Stock.Add();
        rec.RecordType = AccumulationRecordType.Receipt;
        rec.Period     = Date;
        rec.Product    = row.Product;
        rec.Quantity   = row.Quantity;
    }
}
```

Ім'я обробника, `Posting`, фіксоване: платформа викликає його під час проведення документа і
записує зібрані ним записи. Редактор доповнює імена під час набору (Ctrl+Space), тож
точне написання кожного поля завжди за одне натискання клавіші.

## 5. Оновіть базу даних і запустіть

1. Натисніть **Оновити базу даних** на панелі інструментів. Application Studio записує застосунок у базу
   і створює таблиці.
2. **Налагодження → Запустити без налагодження → Workspace (GUI)** запускає Application Workspace на тій самій базі.
3. В Application Workspace додайте два-три товари, потім створіть надходження, заповніть його таблицю і проведіть його.

Ви не намалювали жодної форми. Платформа згенерувала їх за метаданими. Щоб намалювати
власні, див. [Форми](../forms/).

## 6. Прочитайте залишок

Запит, що читає залишок регістру на поточний момент:

```sql
SELECT B.Product, B.QuantityBalance
FROM AccumulationRegister.Stock.Balance(&At) AS B
```

Виконайте його з коду:

```c
var q = new Query("SELECT B.Product, B.QuantityBalance FROM AccumulationRegister.Stock.Balance(&At) AS B");
q.SetParameter("At", CurrentDate());
var table = q.Execute().Unload();
```

або зробіть із нього **Звіт** і дайте компонувальнику звіту згрупувати, підсумувати й надрукувати його. Див.
[Запити і звіти](../queries-and-reports/).

## Що далі

- Поставте точку зупинки в `Posting` і скористайтеся **Налагодження → Почати налагодження → Workspace (GUI)**, щоб пройти його покроково.
- Додайте роль у **Загальні → Ролі**, щоб визначити, хто може читати й проводити надходження.
- Доручіть ті самі кроки асистенту:
  [Створення застосунку з асистентом](https://github.com/open-enterprise-solutions/enterprise/blob/develop/docs/public/ai-quickstart.md).
