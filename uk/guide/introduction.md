## Що таке OpenES

OpenES — платформа для бізнес-застосунків. Ви не пишете застосунок
з нуля. Ви його **описуєте**, а решту платформа будує за описом:

| Ви описуєте | Платформа створює |
|---|---|
| Об'єкти, які веде бізнес: товари, клієнти, накладні, залишки на складі | Таблиці бази даних, що змінюються разом з описом |
| Що бачить користувач | Форми, списки, діалоги вибору (генеруються, якщо ви їх не намалювали) |
| Правила: що робить проведення накладної, що може містити поле | Скомпільований код, що виконується під час кожного запису, проведення чи команди |
| Питання: залишки за складами, продажі за місяцями | Запити, що виконуються як SQL, і звіти з підсумками та розшифровкою |

Той самий застосунок працює як настільна програма і в браузері. Application Studio і Application Workspace
відкривають порт асистента (MCP), тож ШІ-асистент може будувати й перевіряти застосунок
разом з вами.

## Терміни, що вживаються в посібнику

| Термін | Значення |
|---|---|
| **База** (інформаційна база) | Дані одного застосунку та його опис, що зберігаються разом в одній базі даних |
| **Застосунок** | Опис: його метадані, форми, модулі, ролі |
| **Метадані** | Об'єкти, які оголошує застосунок: довідники, документи, регістри, звіти… Див. [Дерево метаданих](../metadata-tree/) |
| **Довідник** | Перелік чогось: товари, клієнти, склади |
| **Документ** | Подія з датою: надходження, накладна, розрахункова відомість |
| **Проведення** | Що документ робить із регістрами, коли його підтверджено |
| **Регістр** | Місце, де накопичуються факти: залишки, ціни в часі, бухгалтерські проводки |
| **Модуль** | Код, прив'язаний до об'єкта, форми або всього застосунку |
| **Форма** | Вікно, у якому працює користувач |
| **Оновлення бази даних** | Запис зміненого застосунку в базу, що перебудовує її таблиці |

## Дві програми, дві ролі

- **Application Studio** (`appstudio`, OES Application Studio): де застосунок створюють. Тут працює розробник.
- **Application Workspace** (`appworkspace`, OES Application Workspace): де застосунком користуються. Тут користувачі вводять
  документи й формують звіти.

Обидві відкривають ту саму базу. Application Studio редагує застосунок, записує його в базу даних і може запустити
Application Workspace під своїм налагоджувачем.

## Де зберігається база

| Вид | Де | Для чого |
|---|---|---|
| **Файлова база** | Папка на диску. Рушій Firebird входить до пакета, тому сервер встановлювати не треба | Розробка, один користувач, невеликий офіс |
| **База PostgreSQL** | Ваш сервер PostgreSQL | Кілька користувачів, промислова експлуатація |

[Кластер застосунків](../application-server/) обслуговує багато баз, Firebird і PostgreSQL
разом, з однієї папки сервера — кожну базу у власному серверному процесі.

## Мови

Інтерфейс доступний англійською, російською та українською. Застосунок оголошує власні
мови, і кожен заголовок у ньому можна написати кожною з них.
