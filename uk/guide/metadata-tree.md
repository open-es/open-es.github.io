Дерево ліворуч в Application Studio — це весь застосунок. Його корінь — сам
застосунок із його ім'ям і властивостями. Під ним —
**Загальні** об'єкти, що не належать жодному окремому прикладному об'єкту, далі прикладні об'єкти
в тому порядку, в якому їх зазвичай читають.

## Прикладні об'єкти

| Група | Що містить | Приклад |
|---|---|---|
| **Інтеграція → HTTP-сервіси** | Адреси, на яких застосунок відповідає на HTTP-запити, кожна зі своїм обробником | Прийом замовлень із вебсайту |
| **Константи** | По одному значенню, на всю базу | Назва організації, основна валюта |
| **Довідники** | Переліки, плоскі або ієрархічні, з визначеними елементами | Товари, клієнти, склади |
| **Документи** | Події з датою і номером; проведення записує їх у регістри | Надходження, накладна, розрахункова відомість |
| **Журнали документів** | Один список документів кількох видів | Усі документи продажу |
| **Перерахування** | Закритий набір значень, зафіксований у застосунку | Статус замовлення, вид ставки ПДВ |
| **Обробки** | Інструменти з формами й кодом, але без власних збережених даних | Імпорт, групова зміна |
| **Звіти** | Питання до даних, із власними компонувальниками | Залишки на складі, продажі за місяцями |
| **Плани видів характеристик** | Види аналітики, якими може бути значення | «Аналітика рахунку» |
| **Плани рахунків** | Рахунки, їхня ієрархія і те, у розрізі чого ведеться кожен | Головна книга |
| **Плани видів розрахунку** | Види нарахувань і утримань та їхня взаємодія | Оклад, премія, лікарняний |
| **Регістри відомостей** | Факти за ключем, за потреби в часі | Ціни, курси валют, посада працівника |
| **Регістри накопичення** | Кількості й суми, що складаються в залишки чи обороти | Склад, взаєморозрахунки |
| **Регістри бухгалтерії** | Подвійний запис за планом рахунків | Бухгалтерська книга |
| **Регістри розрахунку** | Результати розрахунку зарплати за періодами: витіснення, база, перерахунок | Нарахування |
| **Послідовності** | Порядок, у якому проводилися документи, для перепроведення з певної точки | Порядок розрахунку собівартості |

Який регістр вибрати:

- **значення, що змінюється в певні моменти часу** (ціна, курс, посада) → регістр відомостей;
- **суми, що складаються** (залишок на складі, борг клієнта) → регістр накопичення;
- **подвійний запис** → регістр бухгалтерії за планом рахунків;
- **нарахування, що витісняють одне одного й слугують базою одне одному** (лікарняний витісняє оклад, премія — частка
  окладу) → регістр розрахунку за планом видів розрахунку.

## Усередині об'єкта

Відкритий об'єкт має деякі з цих груп:

| Група | Що це |
|---|---|
| **Реквізити** | Його поля. Кожне має тип: рядок, число, дата, посилання на інший об'єкт… |
| **Таблиці** | Його табличні частини: рядки накладної, учасники групи |
| **Виміри / Ресурси** | Для регістрів: за чим ідентифікується запис і що він містить |
| **Значення перерахування** | Для перерахувань: значення |
| **Форми** | Вікна для його показу; без них платформа генерує форму сама. Див. [Форми](../forms/) |
| **Команди** | Дії, які об'єкт пропонує на своїх формах і в навігації |
| **Шаблони** | Друковані форми та інші макети; а також компонувальники — що звіт читає і як групує та підсумовує прочитане |
| **Модулі** | Модуль об'єкта (код, що виконується під час запису або проведення об'єкта) і модуль менеджера (код для всього виду). Див. [Модулі та мова](../modules-and-language/) |

## Загальні

| Група | Що містить |
|---|---|
| **Загальні модулі** | Код, спільний для всього застосунку |
| **Загальні форми** | Форми, що не належать жодному об'єкту |
| **Загальні команди, Групи команд** | Дії та їх групування в інтерфейсі |
| **Загальні шаблони** | Макети, що не належать жодному об'єкту |
| **Регламентні завдання, Визначені завдання** | Код, що виконується за розкладом у власному сеансі |
| **Обробники подій** | Один обробник для тієї самої події багатьох об'єктів |
| **Параметри сеансу** | Значення, що задаються під час входу й читаються кодом до кінця сеансу |
| **Функціональні опції** | Перемикачі, що показують або ховають частини застосунку |
| **Загальні реквізити** | Один реквізит, доданий одразу до багатьох об'єктів |
| **Картинки** | Значки і зображення |
| **Розділи** | Панель навігації: те, що користувачі бачать першим |
| **Ролі** | Права на об'єкти та операції. Роль або надає, або обмежує; правила на рівні рядків задаються в коді ролі |
| **Мови** | Мови, якими написано заголовки |

## Як дерево стає таблицями

Кожен об'єкт, що зберігається, стає таблицями бази даних, а кожен реквізит — колонкою. Коли ви
натискаєте **Оновити базу даних**, Application Studio порівнює застосунок із базою і змінює
лише те, що відрізняється. Визначення таблиць вручну ви не пишете ніколи.
