OES is a platform for building line-of-business applications: stock, accounting, payroll,
sales. This wiki is the user's guide: what the platform is, how to install and build it, how
to make a first application, and how the parts fit together.

## Contents

**Getting started**

1. [Introduction](introduction/): what OES is, and the words used throughout
2. [Installation](installation/): download a build and start it
3. [Building from source](build-from-source/): build it yourself on Windows, Linux or macOS
4. [First steps](first-steps/): a small stock application, from an empty base to a report

**Working in the studio**

5. [The studio](studio/): the window, the menus, saving and running
6. [The metadata tree](metadata-tree/): every kind of object an application is made of
7. [Forms](forms/): what the user sees, and how it is bound to data
8. [Modules and the language](modules-and-language/): where code lives and what it looks like
9. [Queries and reports](queries-and-reports/): reading data back

**Running it**

10. [Application server](application-server/): serving bases without a window
11. [How the platform is built](architecture/): programs, libraries, databases
12. [Pitfalls](pitfalls/): what goes wrong, and what to do
