Know the books? Change the system yourself.

OpenES is a platform for business applications* — stock, accounting, payroll, sales. An AI assistant connects to it directly: tell it in plain words what to keep and what to see, and it builds the catalogs, the documents, the postings and the reports. No specification for a programmer, and no waiting in their queue.

You check the result the way you always have: a posted document, a trial balance, a printed form.

Open the demo Download First steps

The demo opens in a browser, nothing to install. The platform runs on Windows, Linux and macOS.

What it gives you

For implementers

A consultant tells the assistant what used to go into a specification for a programmer. A solution is built faster, with less work and fewer mistakes — and at a fixed price, the difference is yours.

For accountants and finance

A change is checked with postings, balances and a trial balance, not with someone's word that it works. In the workspace the assistant opens a report, finds a document or corrects a value — within your rights.

For the owner

The books change as the business does, without a queue for a programmer. The database is on your own server; people work in the application on Windows, Linux and macOS, or in a browser, on a phone too.

The assistant works in plain sight: the studio shows each step it takes, it describes a change to the database in the books' own words — “the document Order got an attribute” — and every call stays in the journal.

For developers

Under the assistant is an ordinary platform in C++20, and whatever it does can be done by hand. You describe the business in metadata, write its rules in a built-in language and read its data with queries and reports. The platform makes the tables, the forms and the reports, and keeps the database in step as the description changes.

What is inside

An assistant at work
A built-in MCP server: an AI assistant reads, builds and checks an application with the rights of the person who let it in, and every call is journalled.
Registers
Information, accumulation, accounting — a chart of accounts and double entry — and calculation for payroll.
Query language
SELECT over business objects and the registers' balances and turnovers. It runs as SQL on the server, or in memory with the same answer.
Report composer
Groupings, totals, cross tables, drill-down to the records, and each user's saved settings. Prints, and exports to Excel and Word.
The language
C-flavoured CES, or keyword-fenced VES: one compiler to bytecode, with lambdas, exceptions and LINQ.
Studio
Metadata tree, form designer, code editor with completion, query constructor, remote debugger and a git panel.
Access rights
Rights per role, and row-level security written as code in the role. It fails closed.
Server and cluster
A server process per base; the cluster restarts one that falls, and the other bases do not notice. Firebird and PostgreSQL.
Browser
The same application in a browser, on a desktop and on a phone. The server holds the session; the client only draws.
