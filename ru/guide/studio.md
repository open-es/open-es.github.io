Application Studio (`appstudio`, кнопка **Studio (GUI)** в `launcher`) — место, где создаётся приложение: его метаданные,
формы, модули, роли и отчёты. Здесь же приложение записывается в базу данных и запускается под
отладчиком, и здесь рядом с вами может работать ИИ-ассистент.

## Окно

| Часть | Что показывает |
|---|---|
| **Дерево метаданных** (слева) | Приложение: каждый объявленный в нём объект, сгруппированный по видам. См. [Дерево метаданных](../metadata-tree/) |
| **Свойства** | То, что выделено: в дереве, на форме, в таблице. У каждого свойства есть собственная справка |
| **Редакторы** (в центре, вкладками) | Объект, форма, модуль, шаблон: всё, что открыто из дерева |
| **Сообщения, Стек вызовов, Контрольные значения** (внизу) | Сообщения компилятора и панели отладчика, пока он подключён |

## Работа в дереве

Щёлкните правой кнопкой группу (**Справочники**, **Документы**…) → **Новый**, чтобы добавить объект. Правый щелчок по
объекту даёт **Редактировать**, **Удалить**, **Свойства** и открытие его модулей. Двойной щелчок открывает
собственный редактор объекта: его имя, синоним (заголовок, который видят пользователи), комментарий, формы по умолчанию,
а также реквизиты, таблицы, формы, шаблоны и модули.

## Сохранение и обновление базы данных

| Действие | Что делает |
|---|---|
| **Сохранить** (панель инструментов) | Сохраняет изменения открытого редактора в редактируемое приложение |
| **Обновить базу данных** (панель инструментов или **Приложение → Обновить базу данных**) | Записывает отредактированное приложение в базу и перестраивает её таблицы. До этого Application Workspace работает с прежним |
| **Приложение → Вернуть приложение базы данных** | Отменяет правки и возвращается к тому, что хранит база |
| **Приложение → Сохранить приложение / Загрузить приложение** | Записывает приложение в файл или считывает его из файла |
| **Приложение → Сохранить приложение в файлы… / Загрузить приложение из файлов…** | Приложение в виде каталога текстовых файлов, для системы контроля версий ([структура](https://github.com/open-enterprise-solutions/enterprise/blob/develop/docs/public/application-files.md)) |
| **Приложение → Сравнить приложения** | С файлом, с приложением базы данных или два файла между собой |

Обновлению, которое перестраивает хранимые данные, база нужна в монопольное пользование: сначала закройте Application Workspace.

## Запуск и отладка

| Меню «Отладка» | Что делает |
|---|---|
| **Начать отладку → Workspace (GUI) / Workspace (веб)** | Запускает Application Workspace на этой базе, на рабочем столе или в браузере, с подключённым отладчиком |
| **Запуск без отладки** | То же самое, без подключения |
| **Подключить к отладке…** | Подключается к уже запущенному Application Workspace |
| **Продолжить, Шаг с заходом, Шаг с обходом, Остановить отладку** | Обычные команды |
| **Замер производительности** | Замеряет время каждого клиентского вызова и каждой строки скрипта, пока работает Application Workspace |

Щёлкните по полю слева от текста модуля, чтобы поставить точку останова. У точки останова может быть условие (правый щелчок
→ **Условие точки останова…**), и тогда она срабатывает, только когда, скажем, `i > 500`. Во время остановки наведите указатель на
имя, чтобы увидеть его значение, или добавьте его в **Контрольные значения**.

Отладчик работает по TCP, поэтому может подключиться и к веб-серверу.

## Администрирование

| Меню «Администрирование» | Что делает |
|---|---|
| **Пользователи** | Пользователи базы и их роли |
| **Активные пользователи** | Кто подключён сейчас |
| **Журнал регистрации** | Что записала база: входы, записи, проведения |
| **Веб-адреса** | На что база отвечает на веб-сервере помимо своих клиентов |
| **Выгрузить базу данных / Восстановить базу данных / Очистить базу данных** | База в файл и обратно или очистка базы |
| **Окно ассистента** | Беседа с ассистентом, работающим в этой базе |

**Сервис → Тема…** выбирает светлое или тёмное оформление.

## Доступ ассистента (MCP)

**Сервис → Параметры… → Доступ ассистента (MCP)** открывает порт для ассистента на вашей машине, чтобы
ассистент, например Claude Code, мог читать и редактировать приложение, обновлять базу данных, выполнять код и
составлять отчёты. Настройка и первый запрос:
[Создание приложения с ассистентом](https://github.com/open-enterprise-solutions/enterprise/blob/develop/docs/public/ai-quickstart.md).
