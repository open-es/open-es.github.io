## Что такое OpenES

OpenES — платформа для бизнес-приложений. Приложение не пишут с нуля.
Вы его **описываете**, а остальное платформа строит по описанию:

| Вы описываете | Платформа создаёт |
|---|---|
| Объекты, которые ведёт бизнес: товары, клиенты, счета, остатки на складах | Таблицы базы данных, которые меняются вслед за описанием |
| Что видит пользователь | Формы, списки, диалоги выбора (генерируются, если вы их не нарисовали) |
| Правила: что делает проведение счёта, что может содержать поле | Скомпилированный код, который выполняется при каждой записи, проведении или команде |
| Вопросы: остатки по складам, продажи по месяцам | Запросы, выполняемые как SQL, и отчёты с итогами и расшифровкой |

Одно и то же приложение работает как настольная программа и в браузере. И Application Studio, и Application
Workspace открывают порт для ассистента (MCP), поэтому ИИ-ассистент может создавать и проверять приложение
вместе с вами.

## Слова, которые используются далее

| Слово | Значение |
|---|---|
| **База** (информационная база) | Данные одного приложения и его описание, хранящиеся вместе в одной базе данных |
| **Приложение** | Описание: его метаданные, формы, модули, роли |
| **Метаданные** | Объекты, которые объявляет приложение: справочники, документы, регистры, отчёты… См. [Дерево метаданных](../metadata-tree/) |
| **Справочник** | Список чего-либо: товары, клиенты, склады |
| **Документ** | Событие с датой: поступление, счёт, расчётная ведомость |
| **Проведение** | Что документ делает с регистрами, когда его подтверждают |
| **Регистр** | Где накапливаются факты: остатки, цены во времени, бухгалтерские проводки |
| **Модуль** | Код, привязанный к объекту, форме или всему приложению |
| **Форма** | Окно, в котором работает пользователь |
| **Обновление базы данных** | Запись изменённого приложения в базу, при которой перестраиваются её таблицы |

## Две программы, две роли

- **Studio** (`appstudio`, OES Application Studio): здесь приложение создают. Здесь работает разработчик.
- **Workspace** (`appworkspace`, OES Application Workspace): здесь приложением пользуются. Здесь пользователи вводят
  документы и формируют отчёты.

Обе программы открывают одну и ту же базу. Application Studio редактирует приложение, записывает его в базу данных и может
запустить Application Workspace под своим отладчиком.

## Где хранится база

| Вид | Где | Для чего |
|---|---|---|
| **Файловая база** | Папка на диске. Движок Firebird входит в пакет, поэтому сервер устанавливать не нужно | Разработка, один пользователь, небольшой офис |
| **База PostgreSQL** | Сервер PostgreSQL, который вы запускаете сами | Несколько пользователей, промышленная эксплуатация |

[Кластер приложений](../application-server/) обслуживает много баз, Firebird и PostgreSQL
вместе, из одной папки сервера — каждую базу в собственном серверном процессе.

## Языки

Интерфейс доступен на английском, русском и украинском. Приложение объявляет собственные
языки, и каждый заголовок в нём можно задать на каждом из них.
