На этой странице собирается небольшое складское приложение: товары, документ поступления, который приходует
товар, регистр, который хранит остаток, и отчёт, который его читает. Это занимает около пятнадцати
минут и по разу затрагивает каждую часть Application Studio.

## 1. Создать базу

1. Запустите `launcher` и нажмите **Добавить**.
2. Назовите базу `Stock`, выберите **Файл (локальная база данных)** и укажите пустую папку.
3. Нажмите **Сохранить соединение**, выделите базу и нажмите **Studio (GUI)**.

Application Studio открывается с пустым приложением. Слева —
[дерево метаданных](../metadata-tree/); если выделить в нём что-либо, показываются его свойства.

## 2. Справочник товаров

1. В дереве щёлкните правой кнопкой **Справочники** → **Новый**. Назовите его `Products`.
2. У справочника уже есть код и наименование. Добавьте ещё один реквизит: откройте справочник,
   перейдите в **Реквизиты**, добавьте `Unit` типа *Строка*.

## 3. Регистр, который хранит остаток

1. Щёлкните правой кнопкой **Регистры накопления** → **Новый**. Назовите его `Stock`.
2. В разделе **Измерения** добавьте `Product` типа *Ссылка на справочник: Products*.
3. В разделе **Ресурсы** добавьте `Quantity` типа *Число*.

*Измерение* — то, в разрезе чего ведётся остаток. *Ресурс* — то, что суммируется.

## 4. Документ поступления

1. Щёлкните правой кнопкой **Документы** → **Новый**. Назовите его `Receipt`.
2. В разделе **Таблицы** добавьте таблицу `Goods` с колонками `Product` (*Ссылка на справочник:
   Products*) и `Quantity` (*Число*).
3. В свойствах документа включите `Stock` в **Список записей в регистре**. Это
   регистры, в которые документ может писать.
4. Откройте его **модуль объекта** (правый щелчок по документу → **Открыть модуль объекта**) и напишите,
   что делает проведение:

```c
procedure Posting(Cancel, PostingMode) {
    foreach (row in Goods) {
        var rec = RegisterRecords.Stock.Add();
        rec.RecordType = AccumulationRecordType.Receipt;
        rec.Period     = Date;
        rec.Product    = row.Product;
        rec.Quantity   = row.Quantity;
    }
}
```

Имя обработчика, `Posting`, фиксировано: платформа вызывает его при проведении документа и
записывает собранные им записи. Редактор дополняет имена при вводе (Ctrl+Space), так что
точное написание любого поля всегда в одном нажатии клавиш.

## 5. Обновить базу данных и запустить

1. Нажмите **Обновить базу данных** на панели инструментов. Application Studio записывает приложение в базу
   и создаёт таблицы.
2. **Отладка → Запуск без отладки → Workspace (GUI)** запускает Application Workspace на той же базе.
3. В Application Workspace добавьте два-три товара, затем создайте поступление, заполните его таблицу и проведите его.

Вы не нарисовали ни одной формы. Платформа сгенерировала их по метаданным. Как нарисовать
свои, см. в разделе [Формы](../forms/).

## 6. Прочитать остаток

Запрос, который читает остаток регистра на текущий момент:

```sql
SELECT B.Product, B.QuantityBalance
FROM AccumulationRegister.Stock.Balance(&At) AS B
```

Выполнить его из кода:

```c
var q = new Query("SELECT B.Product, B.QuantityBalance FROM AccumulationRegister.Stock.Balance(&At) AS B");
q.SetParameter("At", CurrentDate());
var table = q.Execute().Unload();
```

или оформить как объект **Отчет**, а группировку, итоги и печать оставить компоновщику отчёта. См.
[Запросы и отчёты](../queries-and-reports/).

## Что дальше

- Поставьте точку останова в `Posting` и пройдите обработчик по шагам через **Отладка → Начать отладку → Workspace (GUI)**.
- Добавьте роль в **Общие → Роли**, чтобы решить, кто может читать и проводить поступления.
- Поручите те же шаги ассистенту:
  [Создание приложения с ассистентом](https://github.com/open-enterprise-solutions/enterprise/blob/develop/docs/public/ai-quickstart.md).
