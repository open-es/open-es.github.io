Дерево слева в Application Studio — это всё приложение. Его корень —
само приложение, с его именем и свойствами. Под ним идут
**Общие** объекты, которые не принадлежат ни одному прикладному объекту, затем прикладные объекты
в том порядке, в котором их обычно читают.

## Прикладные объекты

| Группа | Что содержит | Пример |
|---|---|---|
| **Интеграция → HTTP-сервисы** | Адреса, на которых приложение отвечает на HTTP-запросы, каждый со своим обработчиком | Приём заказов с сайта |
| **Константы** | По одному значению на всю базу | Название компании, основная валюта |
| **Справочники** | Списки чего-либо, плоские или иерархические, с предопределёнными элементами | Товары, клиенты, склады |
| **Документы** | События с датой и номером; проведение записывает их в регистры | Поступление, счёт, расчётная ведомость |
| **Журналы документов** | Один список по документам нескольких видов | Все документы продаж |
| **Перечисления** | Закрытый набор значений, зафиксированный в приложении | Статус заказа, вид ставки НДС |
| **Обработки** | Инструменты с формами и кодом, но без собственных хранимых данных | Загрузка, групповое изменение |
| **Отчеты** | Вопросы к данным, со своими компоновщиками | Остатки на складе, продажи по месяцам |
| **Планы видов характеристик** | Виды аналитики, которыми может быть значение | «Аналитика счёта» |
| **Планы счетов** | Счета, их иерархия и разрезы учёта по каждому | Главная книга |
| **Планы видов расчёта** | Виды начислений и удержаний и их взаимодействие | Оклад, премия, больничный |
| **Регистры сведений** | Факты по ключу, при необходимости во времени | Цены, курсы валют, должность сотрудника |
| **Регистры накопления** | Количества и суммы, которые складываются в остатки или обороты | Склад, взаиморасчёты |
| **Регистры бухгалтерии** | Двойная запись по плану счетов | Главная книга |
| **Регистры расчёта** | Результаты расчёта зарплаты по периодам: вытеснение, база, перерасчёт | Начисления |
| **Последовательности** | Порядок, в котором проводились документы, для перепроведения с определённой точки | Порядок расчёта себестоимости |

Какой регистр выбрать:

- **значение, которое меняется в моменты времени** (цена, курс, должность) → регистр сведений;
- **суммы, которые складываются** (остаток на складе, долг клиента) → регистр накопления;
- **двойная запись** → регистр бухгалтерии по плану счетов;
- **начисления, которые вытесняют друг друга и служат друг другу базой** (больничный вытесняет оклад, премия — доля
  оклада) → регистр расчёта по плану видов расчёта.

## Внутри объекта

У любого открытого объекта есть некоторые из этих групп:

| Группа | Что это |
|---|---|
| **Реквизиты** | Его поля. У каждого есть тип: строка, число, дата, ссылка на другой объект… |
| **Таблицы** | Его табличные части: строки счёта, участники группы |
| **Измерения / Ресурсы** | У регистров: по чему определяется запись и что она хранит |
| **Значения перечисления** | У перечислений: сами значения |
| **Формы** | Окна, в которых он показывается; если их нет, платформа генерирует форму сама. См. [Формы](../forms/) |
| **Команды** | Действия, которые объект предлагает на своих формах и в навигации |
| **Шаблоны** | Печатные формы и другие шаблоны; а также компоновщики — что читает отчёт и как группирует и подытоживает прочитанное |
| **Модули** | Модуль объекта (код, выполняемый при записи или проведении объекта) и модуль менеджера (код для всего вида). См. [Модули и язык](../modules-and-language/) |

## Общие

| Группа | Что содержит |
|---|---|
| **Общие модули** | Код, общий для всего приложения |
| **Общие формы** | Формы, не принадлежащие ни одному объекту |
| **Общие команды, Группы команд** | Действия и их группировка в интерфейсе |
| **Общие шаблоны** | Шаблоны, не принадлежащие ни одному объекту |
| **Регламентные задания, Предопределённые задания** | Код, выполняемый по расписанию, в собственном сеансе |
| **Обработчики событий** | Один обработчик для одного и того же события многих объектов |
| **Параметры сеанса** | Значения, которые задаются при входе и читаются кодом до конца сеанса |
| **Функциональные опции** | Переключатели, которые показывают или скрывают части приложения |
| **Общие реквизиты** | Один реквизит, добавленный сразу ко многим объектам |
| **Картинки** | Значки и изображения |
| **Разделы** | Панель навигации: что пользователи видят первым |
| **Роли** | Права на объекты и операции. Роль либо разрешает, либо ограничивает; правила на уровне строк живут в коде роли |
| **Языки** | Языки, на которых пишутся заголовки |

## Как дерево становится таблицами

Каждый хранимый объект становится таблицами базы данных, а каждый реквизит — колонкой. Когда вы
нажимаете **Обновить базу данных**, Application Studio сравнивает приложение с базой и меняет
только то, что отличается. Определения таблиц вручную вы не пишете никогда.
