OES написана на C++20 с wxWidgets. Она собирается MSVC на Windows, GCC на Linux и
Clang на macOS, и CI прогоняет тесты на всех трёх. Полное описание — в
[ARCHITECTURE.md](https://github.com/open-enterprise-solutions/enterprise/blob/develop/docs/ARCHITECTURE.md).

## Программы и библиотеки

```
   appstudio      appworkspace                   browser
        │               │                           │
        └───────┬───────┘                           ▼
                ▼                               webserver
            frmclient   (draws the forms)           │
                │                                   │
                │◄──── client protocol ────────────►│
                ▼                                   ▼
   fileserver (a file base,          appcluster ─► appserver, one or more per base
   in the client's own process)                     │
                │                                   │
                └──────────────┬────────────────────┘
                               ▼
               frmserver   (the forms, on the server)
                               ▼
                backend    (the engine, no UI)
                               │
              Firebird · PostgreSQL · ODBC · SQLite
```

| Часть | Что делает |
|---|---|
| **backend** | Движок: метаданные, компилятор и интерпретатор байт-кода, движок запросов и компоновщик отчётов, сеансы, блокировки, задания, слой базы данных, сервер отладчика. Интерфейса у него нет |
| **frmserver** | Формы и их элементы, которые живут рядом с движком; а также инструменты ассистента (MCP) |
| **frmclient** | Лежит под Application Studio и Application Workspace: рисует то, что говорят формы сервера, и отправляет обратно то, что сделал человек. Кода приложения он не выполняет |
| **deskgui** | Пользовательский интерфейс настольных программ: элементы и диалоги, которые платформа рисует сама, светлое и тёмное оформление |
| **core** | Лежит под каждой библиотекой: строки, числа, даты, сериализация, текст запроса, сеть и TLS, картинки (PNG и SVG) |
| Программы | Каждая выбирает, как добраться до базы, и передаёт работу библиотекам. `launcher` и `coderunner` работают прямо поверх движка |

## Внутри движка

| Подсистема | Что делает |
|---|---|
| **Метаданные** | Хранят приложение как дерево объектов. Обновление базы данных сравнивает его с базой и меняет таблицы по разнице, сначала показывая точный DDL |
| **Компилятор** | Лексер, парсер, байт-код (82 опкода), интерпретатор, LINQ. Скомпилированные модули кэшируются по версии приложения |
| **Движок запросов** | Разбирает язык запросов, переводит его в диалект базы данных или выполняет в памяти, когда SQL не может этого выразить |
| **Компоновщик** | Превращает настройки отчёта в запрос, а его результат — в табличный документ |
| **Сеансы** | По одному на пользователя, задание или службу. Сеанс держит своё соединение, выполняемый код и свои окна |
| **Блокировки** | Блокировки записей, общие для процессов, чтобы два сервера на одной базе не перезаписывали друг друга |
| **Задания** | Регламентные и фоновые задания; задание выполняется один раз на все серверы, работающие с базой |
| **Слой базы данных** | Один интерфейс поверх Firebird, PostgreSQL, ODBC и SQLite; каждый оператор подготавливается, а не склеивается из строк |
| **Отладчик** | Сервер в работающем процессе, на порту 7700-7709 этой машины; Application Studio подключается к нему |
| **Сервер MCP** | Доступ ассистента к Application Studio и Application Workspace: около 140 инструментов, на порту собственной машины человека, защищён токеном, каждый вызов записывается в журнал |

## Процессы и базы

Программа, открывающая файловую базу, держит одну эту базу. Сервер приложений тоже держит одну базу,
а кластер запускает по одному или несколько таких серверов на базу, поэтому сбой в процессе одной базы не доходит до
остальных. У каждой базы свой пул соединений, сеансы, блокировки, задания и журнал, и поток
всегда работает на определённую базу: глобальной «текущей» нет.

## Базы данных

| База данных | Роль |
|---|---|
| **Firebird 5** | По умолчанию. Встроен в пакеты: файловой базе сервер не нужен |
| **PostgreSQL** | Промышленная эксплуатация с несколькими пользователями |
| **ODBC** | Путь к другим базам данных |
| **SQLite** | Тесты и журналирование |
