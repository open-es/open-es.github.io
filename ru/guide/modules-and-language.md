## Где живёт код

| Модуль | Принадлежит | Выполняется |
|---|---|---|
| **Модуль объекта** | Справочнику, документу, регистру… | На событиях этого объекта: `BeforeWrite`, `OnWrite`, `BeforeDelete`, `OnDelete`, а у документа — `Posting` и `UndoPosting` |
| **Модуль менеджера** | Виду в целом | Код, который относится ко всем товарам, а не к одному: поиск, выбор формы (`FormGetProcessing`), данные выбора |
| **Модуль формы** | Форме | События формы и её команды |
| **Общий модуль** | Приложению | Общие процедуры, вызываемые откуда угодно |

Обработчик события — это процедура с именем события. Имя фиксировано: процедура с
другим именем никогда не вызывается. Редактор показывает список обработчиков, которые предлагает объект.

Код выполняется везде, где используется объект: в форме, в другом модуле, в фоновом задании, на
сервере приложений. Модуль объекта никогда не рассчитывает на наличие окна.

## Два диалекта, один компилятор

| | CES (в стиле C, по умолчанию) | VES (стиль ключевых слов) |
|---|---|---|
| Функция | `function Compute(x) { return x * 2; }` | `Function Compute(x) Return x * 2 EndFunction` |
| Цикл | `foreach (item in items) { Message(item.Name); }` | `Foreach item In items Do Message(item.Name) EndDo` |

Оба компилируются в один и тот же байт-код. Новые приложения используют CES. Не смешивайте их в одном
модуле: каждый сравнивает и соединяет условия в своём написании — CES `==`, `!=`, `&&`, `||`, `!`;
VES `=`, `<>`, `And`, `Or`, `Not`. Ключевые слова не зависят от регистра, но у каждого ровно одно написание.

## Что есть в языке

- Процедуры и функции, `var`, `if`, `while`, `foreach`, `try … except`
- Лямбды с захватом замыкания
- Многострочные строки, удобные для текстов запросов
- **LINQ**, компилируемый в байт-код:
  ```c
  var q = from o in Orders
          where o.Total > Threshold
          orderby o.Date descending
          select { N = o.Number, V = o.Total };
  ```
- Встроенные значения: таблицы и деревья значений, структуры, соответствия, массивы, табличные документы,
  JSON и XML, клиенты HTTP и HTTPS, файлы
- Байт-код кэшируется по версии приложения, поэтому модуль компилируется один раз

## Доступ к данным

| Напишите | Чтобы получить |
|---|---|
| `Catalogs.Products` | Менеджер товаров: создать, найти, выбрать |
| `Documents.Receipt` | Менеджер поступлений |
| `InformationRegisters.Prices`, `AccumulationRegisters.Stock`… | Регистр |
| `Constants.CompanyName` | Константу |
| `Data.Catalogs.Products` | Тот же справочник как источник LINQ |
| `new Query("SELECT …")` | Запрос; см. [Запросы и отчёты](../queries-and-reports/) |

Внутри модуля объекта документа `RegisterRecords.Stock` — набор записей, которые документ
запишет в регистр `Stock` при проведении.

## Проба кода без базы

`coderunner` — черновое окно: напишите скрипт, проверьте синтаксис, выполните его. Ему не нужны ни база,
ни приложение.

## Заголовки на нескольких языках

Заголовок пишется на каждом языке, который объявляет приложение, одной строкой:
`en = 'Employee'; ru = 'Сотрудник'; uk = 'Працівник';`. В коде `Tstr(text)` выбирает язык
пользователя.
